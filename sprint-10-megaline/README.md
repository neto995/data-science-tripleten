# Sprint 10 · Megaline Plan Classification

Machine learning classification project developed as part of the TripleTen Data Science bootcamp.

The goal is to recommend whether a mobile customer should use the **Smart** or **Ultra** plan based on monthly customer behavior.

### Main tools
- Python
- Pandas
- Scikit-learn
- Random Forest

### Final result
- Test Accuracy: **82.43%**
- Dummy Baseline: **72.47%**
- Improvement: **+9.96 percentage points**
